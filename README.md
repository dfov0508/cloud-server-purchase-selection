## 计费模式：包年包月还是按量计费，取决于你能预测多久的用量

能预测使用时长、业务长期稳定，选包年包月；用量波动大或者只是临时用，选按量计费。

腾讯云 CVM 提供两种计费模式。包年包月是预付费，先购买再使用，系统根据你选择的云服务类型和数量计算价格并从账户扣费。按量计费是后付费，按需申请和使用资源，结算时根据实际用量出账。

官网给的判断标准很直接：资源需求长期稳定的成熟业务，选包年包月；业务发展波动较大、无法准确预测用量，或者资源使用是临时、突发的，选按量计费。电商购物高峰期就是典型的按量计费场景。

这里有个常见的理解偏差：按量计费买到的是灵活，不一定省钱。一台 7×24 小时常驻的机器，按量计费按小时累计，月底账单往往比你下单时预估的高。反过来，只用三天的测试环境如果买了包年包月，剩下的 362 天都在浪费。先想清楚这台机器三个月后还在不在跑，答案基本就出来了。

## 地域和可用区：选错了，延迟和账单都会提醒你

地域选离最终用户最近的，需要内网互通的机器放在同一个地域。

腾讯云的地域之间完全隔离。选地域有两条原则，第二条最容易被忽略，因为它直接写进账单：同一地域的 CVM 实例可以通过内网互相通信，免费；不同地域的实例不能走内网，只能通过公网通信，收费。

所以如果你的 Web 服务器和数据库需要频繁通信，把它们放在不同地域，等于主动给自己加了一笔流量费。最终用户在长三角，上海地域就是更合适的选择；用户主要在海外，才需要考虑境外地域。

可用区是地域内部的独立物理基础设施。每个可用区有各自的供电和制冷，常见的故障点不在可用区之间共享。官方的说法是，即使是火灾、龙卷风、洪水这类灾难，也只影响单个可用区。想让多台机器扛住单点故障，做法是把它们分散到同地域的不同可用区里，而不是全堆在一个可用区图省事。

## 下单页面上几个容易点错的选项

镜像、存储、网络三块都有默认值，但默认值不一定适合你。

**镜像**分四类：公共镜像、服务市场镜像、共享镜像、自定义镜像。公共镜像是官方系统盘；服务市场镜像预装了运行环境；共享镜像是其他腾讯云用户共享给你的自定义镜像，一个镜像最多可以共享给 500 个腾讯云用户，而且共享副本不计入你的镜像配额；自定义镜像是你自己做的，通常用于批量部署和备份运行环境。

**操作系统**方面，CVM 支持自研的 TencentOS Server，以及 Windows Server、OpenCloudOS、CentOS、CentOS Stream、Ubuntu、Red Hat（商业版）、Debian、FreeBSD、OpenSUSE、AlmaLinux、CoreOS、Fedora、Rocky Linux 等第三方系统。习惯了哪个就选哪个，迁移成本比想象中低。

**网络**这块要分清两组概念。内网 IP 是给使用内网 IP 作为源 IP 的客户端提供服务用的，公网 IP 是给使用公网 IP 作为源 IP 的客户端用的，两者通过 NAT 直接映射。EIP 则是地域级的固定公网 IP，可以把地址快速重新映射到账户里的另一台 CVM 或 NAT 网关，实例出故障时用它把流量顶上去，比重新解析域名快得多。

安全组的逻辑是白名单：把实例放进你指定的安全组，在控制台的安全组界面里指定组间通信规则，以及哪些 IP 子网可以和实例通信。默认放开全部端口是最常见的错误，尤其是数据库端口。

数据备份方面，用 CBS 的场景下可以创建自定义系统盘镜像和数据盘快照来备份业务数据。对数据安全要求更高的，还可以另买第三方定制备份服务。

## 几个买之前常问的问题

**包年包月和按量计费到底怎么选？** 长期稳定的业务选包年包月，需求波动大或者临时突发的选按量计费。判断依据是你对使用时长的预测能力，不是价格标签。

**内网 IP 和公网 IP 有什么区别？** 内网 IP 服务于使用内网 IP 作为源 IP 的客户端，公网 IP 服务于使用公网 IP 作为源 IP 的客户端，两者通过 NAT 直接映射。不需要对外提供服务的机器，不必配公网 IP。

**云服务器上的数据怎么备份？** 用 CBS 时，创建自定义系统盘镜像和数据盘快照即可。数据安全要求高的可以加购第三方定制备份服务。

**地域怎么选？** 两条原则：离最终用户最近，需要内网通信的机器选同一地域。跨地域只能走公网，而且收费。

**可用区之间隔离到什么程度？** 每个可用区运行在独立且物理上不同的基础设施内，供电、制冷等常见故障点不共享，罕见的灾难也只影响单个可用区。

**一个镜像最多能共享给多少人？** 500 个腾讯云用户，共享副本不计入你的镜像配额。
